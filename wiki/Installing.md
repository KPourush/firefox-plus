# Installing

Firefox+ is distributed as a signed APK on the [Releases](https://github.com/KPourush/firefox-plus/releases) page. The easiest way to install it and get updates is [Obtainium](https://github.com/ImranR98/Obtainium), which installs and updates apps directly from GitHub releases.

## With Obtainium (recommended)

1. Install Obtainium on your phone.
2. Open this link on the phone: [Add Firefox+ to Obtainium](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/KPourush/firefox-plus).<br>
   Or, in Obtainium, tap **Add app** and paste `https://github.com/KPourush/firefox-plus`.
3. Tap **Install**. Android will ask you to allow installs from Obtainium the first time.

Obtainium checks the repository for new releases and offers them as updates. New Firefox versions normally arrive on Wednesdays, after the [weekly check](How-Updates-Work).

## By hand

Download the `.apk` from the [latest release](https://github.com/KPourush/firefox-plus/releases/latest) and open it on the phone. You'll have to repeat this for each update.

## Requirements

- An **arm64** (`arm64-v8a`) Android phone. That covers nearly every phone from the last several years.
- Firefox+ installs **next to** the Play Store Firefox (app ID `org.mozilla.firefox_plus`). The two don't share tabs, history or settings; use [Tab Mover](Tab-Mover) to bring your tabs over.
